# 基金助手评分模型调研与新方案

## 1. 结论

当前项目里的旧模型只是“低位 + 回调 + 仓位不足”的个人纪律规则，不能作为产品级金融工具的核心模型。它最大的问题是：过度依赖短期净值位置和短期涨跌，缺少基金质量、组合目标、风险承受能力、资产配置、再平衡和同类比较。

产品级方案应该改成“三层模型”：

1. 基金质量评分：先判断一只基金值不值得长期留在池子里。
2. 组合配置评分：再判断当前组合和目标配置偏离多少。
3. 买入执行评分：最后决定今天的新资金应该买哪只、买多少。

核心原则：不预测明天涨跌，不做自动交易；以资产配置和再平衡为主，以估值和回撤为辅。

## 2. 市场调研摘要

### 2.1 Morningstar

Morningstar 的基金星级评级强调“同类基金之间的风险调整后收益比较”。它不是只看收益，而是把基金放在相同类别里比较，并对风险做惩罚。Morningstar 还区分了后视型星级评级和前瞻型 Medalist Rating。Medalist Rating 关注 People、Process、Parent，并将费用作为重要输入。

可借鉴点：

- 基金必须同类比较，不能拿债券基金和海外科技基金直接比。
- 评分不能只看收益，要看风险调整后收益。
- 费用是长期收益的重要拖累。
- 主动基金需要看基金经理、策略稳定性和基金公司。

### 2.2 天天基金

天天基金的基金诊断从择时能力、稳定性、抗风险、收益率、选证能力五个角度做综合评分。

可借鉴点：

- 国内用户能理解“收益率、稳定性、抗风险”这类维度。
- 主动基金和指数基金应区别处理。
- 不应只输出一个总分，要展示分项。

### 2.3 Betterment

Betterment 的核心不是预测涨跌，而是根据目标资产配置做再平衡。它会优先使用现金流、分红和新增资金买入低配资产；当偏离超过容忍区间时，才做主动再平衡。它还会避免频繁的小额交易。

可借鉴点：

- 买入建议应该优先补低配资产。
- 新增资金天然是再平衡机会。
- 设置偏离阈值，避免每天微调。
- 不强行用完预算。

### 2.4 Wealthfront

Wealthfront 使用现代投资组合理论，根据风险承受能力和税务情况构建全球多资产 ETF 组合，并做再平衡、股息再投资和税损收割。其组合目标是长期风险收益权衡，而不是短期择时。

可借鉴点：

- 先确定用户风险等级，再确定目标资产配置。
- 低成本、分散化、被动 ETF 是默认优先项。
- 再平衡和税务/交易成本约束比短期信号更重要。

### 2.5 Schwab Intelligent Portfolios

Schwab 强调组合目标资产配置与风险画像匹配，组合随市场变化偏离目标后自动再平衡。

可借鉴点：

- 风险画像决定资产配置。
- 组合偏离目标才是核心动作信号。
- 用户看到的是组合层面的风险，而不是单只基金短期涨跌。

### 2.6 估值温度/百分位类工具

国内常见的估值温度工具通常展示 PE、PB、股债利差、成交活跃度等指标在历史中的百分位。它们通常会声明仅展示历史估值位置和市场情绪，不构成投资建议。

可借鉴点：

- 估值百分位适合做“辅助加减速”，不适合作为唯一买入依据。
- 指数基金可以绑定对应指数估值。
- 不同市场需要不同估值指标：A 股宽基、港股、海外科技、黄金、债券不能共用一套估值逻辑。

## 3. 新模型设计

### 3.1 模型分层

```text
基金池过滤 -> 基金质量评分 -> 组合偏离计算 -> 机会因子 -> 买入金额分配 -> 风控解释
```

### 3.2 基金池过滤

先判断基金是否可以进入推荐池。

硬性剔除：

- 净值数据过期且没有缓存。
- 目标仓位为 0。
- 当前仓位超过目标仓位 120%。
- 单基金超过组合上限。
- 所属资产类别超过上限且不是低风险现金/债券过渡仓。
- 基金成立时间太短，历史数据少于 1 年，除非用户手动设为允许。

产品解释：

- “不能买”不是因为它一定会跌，而是因为它不符合当前组合和风控约束。

### 3.3 基金质量评分 FQS

满分 100，用于判断基金本身是否值得继续买。

#### 指数基金

| 维度 | 权重 | 说明 |
| --- | ---: | --- |
| 跟踪标的质量 | 20 | 宽基、红利、低波、行业、主题，不同资产类别给基础分 |
| 风险调整收益 | 25 | 1 年/3 年收益除以波动，或用简化 Sharpe |
| 最大回撤 | 20 | 回撤越小越好，同类比较 |
| 稳定性 | 15 | 月度正收益比例、波动稳定性 |
| 费用/规模/流动性 | 10 | 低费率、大规模优先 |
| 数据完整性 | 10 | 历史数据长度、净值更新及时性 |

#### 主动基金

| 维度 | 权重 | 说明 |
| --- | ---: | --- |
| 风险调整收益 | 25 | 同类排名，不能跨类别比较 |
| 最大回撤 | 20 | 控制下行能力 |
| 收益稳定性 | 15 | 月度胜率、滚动收益一致性 |
| 基金经理/策略稳定性 | 15 | 后续需要接入外部数据 |
| 费用/规模 | 10 | 费用越低越好，规模极小扣分 |
| 同类相对排名 | 15 | 同类别中分位排名 |

第一版实现时，基金经理和费率数据如果暂时拿不到，先留空，不参与分数，显示“数据待补”。

### 3.4 组合偏离评分 PAS

这是买入金额的主引擎。

定义：

```text
目标金额 = 目标占比 * (当前组合总额 + 今日预算)
缺口金额 = 目标金额 - 当前金额
偏离率 = 缺口金额 / 目标金额
```

买入优先级：

- 缺口金额 <= 0：不买。
- 偏离率 < 5%：一般不买，避免频繁微调。
- 偏离率 5%-15%：可小额补。
- 偏离率 15%-30%：优先补。
- 偏离率 >30%：强优先，但仍受单日预算限制。

这比旧模型更合理，因为新增资金本来就应该优先补低配资产，而不是看哪只今天跌了。

### 3.5 机会因子 OF

机会因子只用于微调，不决定方向。

范围建议：`0.7 - 1.3`

输入：

- 估值百分位：低估加分，高估扣分。
- 净值历史百分位：低位加分，高位扣分。
- 近 1 周/1 月动量：过热扣分，温和回撤加分。
- 最大回撤位置：接近历史大回撤区域时加分，但不能突破风控。

规则：

- 如果基金质量低，机会因子不能把它救成“可以买”。
- 如果组合已经超配，机会因子不能让它继续买。
- 如果估值数据缺失，机会因子默认 1.0，不臆测。

### 3.6 最终买入优先级

```text
买入优先级 = 基金质量系数 * 组合缺口系数 * 机会因子 * 数据可信系数
```

建议：

- 基金质量分 < 50：不新增买入。
- 50-65：只观察。
- 65-80：可作为普通买入候选。
- >80：优先候选。

### 3.7 金额分配

第一版可用如下规则：

1. 计算所有候选基金的“正缺口”。
2. 去掉质量分低于 65 的基金。
3. 对剩余基金计算优先级。
4. 今日预算按优先级比例分配。
5. 单只基金最低 10 元。
6. 单只基金最高不超过今日预算的 50%。
7. 单日最多买 3-4 只。
8. 如果没有足够高质量候选，则保留现金，不强行买。

示例：

```text
基金 A：缺口 300，质量 82，机会 1.1
基金 B：缺口 500，质量 70，机会 0.9
基金 C：缺口 100，质量 55，机会 1.3 -> 质量不足，不买
```

最后只在 A、B 之间分配今日预算。

### 3.8 输出解释

每只基金必须展示四类解释：

- 质量：这只基金本身怎么样。
- 仓位：它现在低配还是超配。
- 市场：估值/净值位置是否便宜。
- 风控：为什么限制金额或禁止买。

示例：

```text
可以买 30 元。
原因：该基金质量分 78，当前仓位比目标低 18%，对应指数估值处于历史 28% 分位。
限制：近一周上涨较快，机会因子降至 0.9；单只基金不超过今日预算 50%。
```

## 4. 与旧模型的区别

| 项目 | 旧模型 | 新模型 |
| --- | --- | --- |
| 核心逻辑 | 低位、回调、仓位不足打分 | 资产配置 + 基金质量 + 机会因子 |
| 是否同类比较 | 否 | 是 |
| 是否考虑基金质量 | 很弱 | 强 |
| 是否考虑目标组合 | 有，但权重不够系统 | 核心主线 |
| 短期涨跌影响 | 较大 | 只做微调 |
| 是否可解释 | 一般 | 分层解释 |
| 产品可信度 | 个人脚本 | 更接近投顾/基金诊断工具的逻辑 |

## 5. 实战依据

这套方案融合的是市场上已经在实战使用的几类方法：

- Morningstar：同类比较、风险调整收益、费用、People/Process/Parent。
- 天天基金：收益率、稳定性、抗风险、择时、选证等分项诊断。
- Betterment：现金流再平衡、漂移容忍区间、避免频繁小交易。
- Wealthfront：风险画像、现代投资组合理论、低成本分散 ETF、再平衡。
- Schwab：目标资产配置和风险等级匹配，偏离目标后再平衡。
- 估值温度工具：估值百分位只作为辅助信号。

但是，本产品自己的模型仍需要回测和实盘记录。不能声称已经有稳定收益，也不能称为投资建议。

## 6. 第一阶段实现建议

### 6.1 先做可落地的数据字段

当前本地数据已经有：

- 基金代码
- 基金名称
- 分类
- 持有金额
- 目标占比
- 历史净值
- 近期收益
- 最大回撤
- 波动率
- 净值位置

第一阶段先实现：

- 基金质量评分简化版。
- 组合偏离评分。
- 机会因子简化版。
- 新金额分配算法。
- 分层解释。

### 6.2 第二阶段补外部数据

后续再接：

- 基金费率。
- 基金规模。
- 基金经理任期。
- 基金评级。
- 指数估值 PE/PB/股债利差。
- 同类基金排名。

### 6.3 第三阶段做验证

- 历史回测。
- 每日建议留痕。
- 与普通月定投对比。
- 与等权补仓对比。
- 统计最大回撤、收益、波动、买入次数、资金利用率。

## 7. 推荐落地版本

第一版新模型不要做复杂机器学习，先做可解释评分：

```text
FundQualityScore = 35% 风险调整收益 + 25% 回撤控制 + 15% 稳定性 + 15% 同类/类别适配 + 10% 数据质量

AllocationNeedScore = min(100, max(0, 缺口金额 / 今日预算 * 50 + 偏离率 * 100))

OpportunityFactor = 1 + 估值低估加成 + 回撤加成 - 过热扣分

FinalPriority = FundQualityScore / 100 * AllocationNeedScore * OpportunityFactor
```

买入金额：

```text
候选基金 = 未触发硬风控 且 FundQualityScore >= 65 且 缺口金额 > 0
今日预算按 FinalPriority 比例分配
单只最低 10 元，最高 今日预算 * 50%
最终金额向下取整到 10 元
```

这套模型比旧模型更适合产品化，因为它先回答“这只基金值不值得长期持有”，再回答“组合现在需不需要补它”，最后才回答“今天价格是否适合多补一点”。
